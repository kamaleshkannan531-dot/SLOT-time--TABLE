EX 04: SLOT TIME TABLE (DJANGO WEB APPLICATION)

SEC / FWAD LAB
🎯 AIM

To design, develop, and deploy an academic slot timetable website for Saveetha Engineering College using HTML, CSS, and the Django Web Framework, incorporating structured multi-slot merging, tea break and lunch break alignments, and comprehensive course mapping.

🛠️ ALGORITHM
  1. Project Initialization: Create a new Django project named timetable_project using the command django-admin startproject timetable_project . and create an application named timetable_app via python manage.py startapp timetable_app.
  2. Project Configuration: In timetable_project/settings.py, register 'timetable_app' in the INSTALLED_APPS array and set template directory path 'DIRS': [BASE_DIR / 'templates'].
  3. Template Design: Create an HTML template (slot_timetable.html) utilizing semantic tags. Employ rowspan="6" to merge the TEA BREAK and LUNCH BREAK across all weekdays (Monday to Saturday), and colspan to span practical/lab periods across multiple hours.
  4. Course Details Table: Construct a secondary lookup table beneath the schedule to map all Course Codes (19AI414, 19AI301, 19AI302, 19CS405, 19CS406, 19EY708) to their complete subject descriptions.
  5. View & Routing Setup: Define a view function slot_timetable(request) in timetable_app/views.py that calls render(request, 'slot_timetable.html'). Link the application routes in timetable_app/urls.py and connect them to the root URL in timetable_project/urls.py.
  6. Execution & Verification: Run the development server with python manage.py runserver and verify the responsive layout and alignment in the browser at http://127.0.0.1:8000/.
